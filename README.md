# ChatGPT Prompt Templates

A collection of structured prompt templates for ChatGPT to help developers get better results when seeking assistance with common development scenarios.

## Available Templates

### 🐛 [Debugging Template](templates/debugging.md)
Get help troubleshooting errors, bugs, and issues in your code.

**Use when:** You're facing errors, unexpected behavior, or need help diagnosing problems.

**Template structure:**
- Context: [project type, framework, version]
- Problem: [error/logs/symptom]
- My hypothesis: [what I think is wrong]
- Goal: [what I need fixed/explained]

### 🏗️ [Architecture Template](templates/architecture.md)
Design system architecture, database schemas, and API contracts.

**Use when:** Planning new systems, microservices, or need architectural guidance.

**Template structure:**
- Business case: [multi-tenant SaaS / microservices / etc.]
- Requirements: [scalability, cost efficiency, speed]
- Constraints: [stack, hosting, budget]
- Task: Design architecture diagram + db schema + api contracts

### 🔧 [Refactoring Template](templates/refactoring.md)
Transform messy code into clean, modular, type-safe, and tested code.

**Use when:** You have working code that needs improvement in quality, maintainability, or structure.

**Template structure:**
- Current Code: [paste your messy code]
- Language/Framework: [your tech stack]
- Specific Issues: [what makes it messy]
- Requirements: [clean, modular, type-safe, tested, with logging]

## How to Use

1. **Choose the right template** for your scenario
2. **Click on the template link** to view the full template and examples
3. **Copy the template structure** and fill in your specific details
4. **Paste into ChatGPT** and get targeted assistance

## Tips for Better Results

- **Be specific and detailed** in your descriptions
- **Include actual code, error messages, or requirements** rather than vague descriptions
- **Mention your tech stack and constraints** to get relevant solutions
- **State your experience level** so responses are appropriately tailored
- **Include what you've already tried** to avoid duplicate suggestions
